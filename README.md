# Soryy — Держись рядом

[Играть в браузере](https://simaleee.github.io/Soryy-web/) · [APK для Android](https://github.com/simaleee/Soryy-updates/releases/tag/v0.6.4)

Тихая история двух братьев, которые ищут близких в Японии после катастрофы.

Управление: WASD/стрелки — движение, E — действие, F — взять или опустить брата, C — тихий шаг, Shift — бег, Esc — пауза. На тросе нажимай Пробел чаще, чтобы сильнее тормозить. Мышь управляет интерфейсом. Геймпад: левый стик — движение, A — действие, X — брат, Start — пауза; A или LT — нажатия тормоза во время спуска.

Качество рендера и показ FPS доступны в главном меню → Изображение. Полноэкранный режим включается кнопкой над игрой. Сохранения браузерной версии хранятся в браузере на этом устройстве.

Здесь размещены готовая WebGL-сборка и её публикация. Исходники Unity и редактируемые ресурсы проекта в этот репозиторий не входят. Архив сборки проверяется по SHA-256 перед размещением на GitHub Pages.
